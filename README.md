# پلتفرم رزرو آنلاین نوبت آکادمی و کلینیک‌های زیبایی (یاسمن رئیسی)

سامانه مدرن، لوکس، موبایل‌محور (Mobile-First) و تماماً فارسی (RTL) برای کشف خدمات، بررسی متخصصین، انتخاب زمان و ثبت نهایی نوبت خدمات زیبایی و آرایش دائم.

---

## ۱. راه‌اندازی و اجرا (Project Setup & Run)

این پروژه با استفاده از **React 19**، **TypeScript**، **Vite** و **Tailwind CSS v4** طراحی و توسعه یافته است.

### اجرای محیط توسعه (Dev Server)

```bash
npm run dev
```

برنامه بر روی آدرس پیش‌فرض `http://localhost:3000` اجرا خواهد شد.

### ساخت نسخه نهایی (Production Build)

```bash
npm run build
```

## ۲. معماری نرم‌افزار (Architecture)

معماری پروژه مبتنی بر **ویژگی‌ها (Feature-Based)**، کامپوننت‌های ماژولار و تفکیک کامل لایه‌های داده، منطق کسب‌وکار و رابط کاربری است:

```
src/
├── app/                  # پیکربندی روتینگ و ارائه‌دهنده‌های سطح بالا
│   └── router/AppRouter.tsx
├── components/           # کامپوننت‌های پایه و مشترک UI
│   ├── ui/               # دکمه‌ها، ورودی‌ها، دیالوگ‌ها (الگوبرداری شده از shadcn/ui)
│   └── shared/           # هدر بیزینس، کارت‌ها و برچسب‌های عمومی
├── features/             # ماژول‌های مجزا با منطق اختصاصی
│   ├── booking/          # منطق، کامپوننت‌ها، فرم، تاییدیه‌ها و استور نوبت‌دهی
│   │   ├── components/   # اجزای گام‌های نوبت‌دهی (DateScroller, TimeSlotPicker, etc.)
│   │   ├── schemas/      # اعتبارسنجی Zod برای فرم مشخصات مشتری
│   │   ├── store/        # استور Zustand برای مدیریت وضعیت جاری رزرو
│   │   └── types/        # تعاریف تایپ‌های جریان رزرو
│   └── tenant/           # چندمستأجری (Multi-Tenant)، بارگذاری کسب‌وکار و هیرو
├── services/             # لایه سرویس‌ها (مستقل از کامپوننت‌ها)
│   ├── availability/     # سرویس محاسبه روزها و ساعت‌های در دسترس
│   └── storage/          # لایه تجرید LocalStorage برای ماندگاری نوبت‌ها
├── config/               # تنظیمات دمو و مستأجرین (Yasaman Raesi, Dr. Ali, etc.)
├── lib/                  # ابزارهای محاسباتی، تاریخ جلالی و قالب‌بندی اعداد فارسی
└── types/                # مدل‌های دامنه نرم‌افزار (Domain Models)
```

## ۳. جریان رزرو نوبت (Booking Flow)

جریان رزرو به صورت هوشمند و مرحله‌ای طراحی شده است:

1. **کشف خدمات (Service Discovery):**
   - دسته‌بندی افقی، خدمت ویژه (Featured) و کارت‌های اختصاصی با عکس و قیمت به تومان.
2. **انتخاب متخصص (Staff Selection):**
   - در صورت نیاز یا تمایل کاربر، امکان انتخاب آرتیست مورد نظر یا انتخاب «اولین متخصص در دسترس».
3. **انتخاب زمان و ساعت (Date & Time):**
   - نوار افقی روزهای هفته جلالی + تفکیک بازه‌های صبح، بعدازظهر و عصر به همراه مسدودسازی روزهای تعطیل (جمعه‌ها).
4. **فرم مشخصات زیباجو (Customer Details):**
   - نام و نام خانوادگی، شماره موبایل با اعتبارسنجی ارقام ایرانی، فیلدهای اختیاری ایمیل و توضیحات پزشکی/سوابق تاتو.
5. **بازبینی و تایید نهایی (Review):**
   - خلاصه هزینه، ضمانت کنسلی، امکان ویرایش مستقیم هر بخش بدون ریست کردن جریان، و دکمه ثبت نهایی.
6. **صفحه موفقیت (Confirmation & Success):**
   - نمایش کد رهگیری یکتا، نکات مراقبتی قبل از مراجعه و دکمه رزرو مجدد با حفظ سوابق.

## ۴. استراتژی موبایل و واکنش‌گرایی (Mobile-First & Touch Experience)

- **هدف‌گذاری نقاط شکست:** سازگاری کامل در عرض‌های `320px`، `360px`، `375px`، `390px`، `412px`، `768px` و `1440px`.
- **نوار چسبان پایین (Mobile Sticky Bar):** با رعایت سقف ۱۵٪ از ارتفاع صفحه، فاصله ایمن (`safe-area-inset`) و نمایش داینامیک نام خدمت و قیمت.
- **اهداف لمسی:** حداقل سایز المان‌های تعاملی ۴۴×۴۴ پیکسل و کلیدهای اصلی ۴۸ پیکسل.
- **عدم اسکرول افقی ناخواسته:** مدیریت دقیق پهنا و استایل `no-scrollbar` روی نوارهای افقی روزها و دسته‌ها.

---

## ۵. طراحی لوکس تیره (Dark Luxury Aesthetic)

- **رنگ‌بندی پایه:** مشکی ابسیدین (`#0b0c0f`)، نوارهای ذغالی گرم (`#14161c`) و هایلایت‌های متالیک طلایی و شامپاینی (`#cbb38d`).
- **تایپوگرافی فارسی:** فونت مدرن وزیری (Vazirmatn) با اعداد و ارقام بومی فارسی در تمامی قیمت‌ها و زمان‌ها.
- **انیمیشن و میکروتعاملات:** بازخورد لمسی در کلیک‌ها (`scale-98`)، ترنزیشن‌های نرم و افکت ملایم نور (Radial Luxury Glow).

---

## ۶. چندمستأجری و افزودن بیزینس جدید (Multi-Tenant Readiness)

برای افزودن یک کسب‌وکار جدید (مانند کلینیک دیگر یا سالن ماساژ):
۱. شیء تنظیمی مطابق با `BusinessConfig` در مسیر `src/config/demo/` بسازید.
۲. کلید اسلاگ آن (مثلاً `clinic-aria`) را به دیکشنری `DEMO_TENANTS` در `src/config/demo/index.ts` بیفزایید.
۳. اکنون مسیر `/booking/clinic-aria` به صورت خودکار خدمات، تم و متخصصین آن کسب‌وکار را لود می‌کند.

---

## ۷. لایه ماندگاری و آمادگی اتصال به API (Storage & Backend Ready)

- هیچ دسترسی مستقیمی به `localStorage` در کامپوننت‌های بصری وجود ندارد.
- تمام عملیات از طریق `appointmentStorage.ts` صورت می‌گیرد (`saveAppointment`, `getAppointments`, `cancelAppointment`).
- در فازهای بعدی، این لایه با فراخوانی متدهای متناظر REST/GraphQL جایگزین خواهد شد بدون اینکه حتی یک خط از کدهای UI تغییر کند.
